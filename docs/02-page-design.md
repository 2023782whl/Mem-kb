# 页面与交互设计

## 视觉方向

整体参考 ima 的轻量知识工作台体验：浅灰白背景、大尺寸问答输入区、内容优先、低装饰。知识资产使用薄荷绿，AI 行为使用紫色，联网能力使用蓝色，图片检索使用珊瑚色作为辅助识别。

### 设计令牌

| 角色 | 建议值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F6F7FB` | 问答首页背景 |
| 主表面 | `#FFFFFF` | 输入区、面板、列表 |
| 主文字 | `#202331` | 标题、正文 |
| 次文字 | `#7D8498` | 描述、元数据 |
| 边框 | `#E6E9F1` | 分栏、输入、列表分隔 |
| AI 紫 | `#6657F5` | 模型、问答主动作 |
| 知识绿 | `#42CFA0` | Workspace、文档、索引完成 |
| 联网蓝 | `#3B82F6` | 联网搜索、网页引用 |
| 图片珊瑚 | `#F26B7A` | 图片检索和图片节点 |
| 警告橙 | `#FF9D45` | 处理中、需注意 |
| 错误红 | `#E95769` | 失败、危险操作 |

- 中文字体：`PingFang SC, Microsoft YaHei, system-ui, sans-serif`。
- 数据与英文：`Inter, system-ui, sans-serif`。
- 卡片圆角 8px，主输入框 16px；避免全站胶囊和嵌套卡片。
- 图标统一使用 Lucide，1.75px 描边；图标按钮提供 tooltip。
- 阴影只用于主输入框、弹层和拖拽状态，常规分区使用 1px 边框。
- 动效只服务于流式回答、上传进度、视图切换和节点聚焦，时长 160-220ms。

## 全局信息架构

```text
/login                                      个人账号登录
/                                           知识问答首页
/c/:conversationId                          问答会话
/documents                                  文档知识
/documents/:workspaceId                     Workspace 文档列表/图谱
/documents/:workspaceId/:assetId            文档详情
/images                                     图片素材
/images/:workspaceId                        图片类目/图谱
```

顶部只保留品牌、“知识问答”“文档知识”“图片素材”和账号菜单。Workspace 作为每个页面的范围选择器，不新增独立后台导航。

## 页面一：知识问答

### 首页结构

```text
┌ 品牌 ─────── 知识问答 | 文档知识 | 图片素材 ─────── 账号 ┐
│                                                            │
│                         知识问答                           │
│                  让运营知识随问随用                         │
│       ┌────────────────────────────────────────────┐       │
│       │ 输入问题、粘贴链接或拖入文件…               │       │
│       │ [模型] [Workspace] [联网] [文档] [图片]     │       │
│       │ [附件] [链接已识别]                    [发送]│       │
│       └────────────────────────────────────────────┘       │
│                                                            │
│  ┌ 高频问题 ──────────┐  ┌ 高频引用文档 ───────────┐      │
│  │ 真实问题与使用次数  │  │ 文档、引用次数、更新时间 │      │
│  └────────────────────┘  └─────────────────────────┘      │
└────────────────────────────────────────────────────────────┘
```

### 输入区

- 模型下拉仅显示后端已启用模型，展示名称、能力和当前状态。
- 联网、文档知识、图片检索是可组合开关；没有开启任何来源时为普通模型对话。
- Workspace 支持全部可见、单选和多选；图片模式可继续选择类目或商品。
- 自动识别粘贴 URL，显示域名、抓取状态和“作为引用/详细解读”选项。
- 图片检索支持上传查询图或输入文本，明确显示“图搜图”或“文搜图”。
- `Enter` 发送、`Shift+Enter` 换行；解析未完成时禁用发送并说明原因。

### 回答与自沉淀

- 回答按段流式显示，网页、文档、图片引用采用不同来源标识。
- 点击引用在右侧抽屉展示原始片段、图片或网页信息，并可进入详情页。
- 回答操作：复制、点赞、点踩、重新生成、“沉淀到 Workspace”。
- 沉淀弹窗只包含目标 Workspace、标题、正文预览和保存按钮。
- 保存成功后显示独立 Markdown 文档入口；写入或索引失败时提供重试，不出现假成功。

### 高频内容

- 高频问题按提问量、继续追问和正向反馈计算。
- 高频文档按真实引用次数排序，并显示所属 Workspace。
- 权限变化后立即从聚合列表移除不可见内容。

## 页面二：文档知识

### 三栏布局

```text
┌ 品牌 ─────── 知识问答 | 文档知识 | 图片素材 ─────── 账号 ┐
├──────────────┬────────────────────┬─────────────────────┤
│ Workspace     │ 文档列表            │ 预览 | 问答 | 图谱   │
│              │                    │                     │
│ 个人空间      │ 搜索  筛选  排序   │ 文档内容/关系画布    │
│ 团队空间      │ 上传              │                     │
│              │                    │                     │
│ 运营知识库    │ 文档行             │                     │
│ 客服知识库    │ 文档行             │                     │
│              │                    │                     │
│ 容量/状态     │ 分页/加载更多       │ 基于当前范围提问     │
└──────────────┴────────────────────┴─────────────────────┘
```

- 左栏创建、切换、重命名和归档个人/团队 Workspace。
- 中栏使用行式列表，显示名称、类型、大小、更新时间、索引状态和更多菜单。
- 右栏在预览、问答和图谱间切换，不离开当前 Workspace。
- 左栏固定 260px，中栏默认 420px，右栏占剩余宽度。

### 文档图谱

- 默认以 Workspace 为中心，展示文档、SOP、策略、人物、项目和主题。
- 点击节点出现紧凑详情浮层：名称、100 字摘要、标签、更新时间、关联数、打开文档。
- 双击节点聚焦并加载下一层；图谱深度限制 1-3 层。
- 小于 1100px 时左栏改抽屉；小于 768px 时切为 Workspace、列表、详情三级页面。

## 页面三：图片素材

### 页面结构

```text
┌ 品牌 ─────── 知识问答 | 文档知识 | 图片素材 ─────── 账号 ┐
├──────────────┬────────────────────┬─────────────────────┤
│ 素材 Workspace│ 类目/商品/图片      │ 详情 | 相似图 | 图谱 │
│              │                    │                     │
│ 个人素材库    │ 一级 > 二级 > 三级  │ 图片预览            │
│ 团队素材库    │ 商品筛选            │ VLM 100 字摘要       │
│              │                    │ OCR/标签/视觉属性     │
│ 类目树        │ 图片缩略图网格       │ 所属类目和商品       │
│              │ 上传/移动/删除       │                     │
└──────────────┴────────────────────┴─────────────────────┘
```

### 类目和图片交互

- 类目树最多三级，只有三级类目可以直接创建商品。
- 选中商品后展示稳定比例的图片网格；hover 只出现选择框和常用动作。
- 上传后依次展示上传、VLM 分析、向量化和可检索状态。
- 图片详情显示原图、100 字摘要、OCR、标签、尺寸、文件大小和相似图片。
- 顶部搜索可在文搜图和上传图片搜图之间切换。

### 图片图谱

- 中心可以是 Workspace、类目、商品或图片。
- 类目、商品、图片、场景、风格使用稳定颜色和图标，不使用随机配色。
- 点击图片节点显示缩略图和 VLM 摘要；点击“查看详情”进入对应商品。

## 设计签名

产品的核心体验是“问答、原文、关系和沉淀连续工作”：用户从答案引用进入原文，从原文查看图谱，再把修订后的答案保存回 Workspace。整个循环不跳到独立 GBrain 后台。
