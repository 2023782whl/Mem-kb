# 产品范围

## 产品定位

Mem-kb 知识库模块以 LLM Wiki/内容解析层连接 GBrain，重点沉淀企业运营资产、SOP、素材和个人运营策略。GPT-5.5 等模型负责理解与生成，GBrain 负责长期知识、检索和关系图谱。

核心闭环：

```text
登录 -> 创建 Workspace -> 上传/采集内容 -> 解析并写入 GBrain
     -> 检索/问答 -> 带引用回答 -> 人工确认 -> 一键沉淀为 Markdown
```

## 租户与业务分区

产品层统一使用 `Workspace（知识库）` 作为业务知识容器，避免再增加一个含义重复的“知识库”层级。

```text
Tenant 企业租户
├── Personal Workspace
│   └── 个人运营策略、经验、打法
└── Team Workspace
    ├── 电商运营知识库
    ├── 电商客服知识库
    └── 电商素材库
```

- 每个 Workspace 具有 `tenant_id`、`owner_id`、`scope(personal|team)` 和 `kind(document|image|mixed)`。
- 个人 Workspace 仅本人可见；团队 Workspace 根据 Owner、Editor、Viewer 授权。
- 一个 Workspace 对应一个稳定的 GBrain `source_id`，从知识引擎层阻断跨 Workspace 检索。

## 个人账号登录

- 邮箱 + 密码登录。
- HttpOnly Cookie 会话，不把 Token 放在 localStorage。
- 记住登录、退出登录、会话过期提示和登录失败限流。
- 首次启动通过初始化脚本创建 Owner，不在第一阶段开放注册。
- 前端不提供独立权限管理页面，后端仍真实实现租户、角色和 ACL。

## 页面一：知识问答

### 问答能力

- 切换已启用模型，默认 GPT-5.5；模型密钥只保存在服务端。
- 可单独或组合开启联网搜索、文档知识问答、图片检索。
- 图片检索支持图搜图和文搜图。
- 支持粘贴 URL，对网页正文进行抓取、清洗、详细解读和引用。
- 可选择全部可见 Workspace、单个 Workspace、多 Workspace 或指定文件作为范围。
- 回答按 SSE 流式输出，并分别标识网页引用、文档引用和图片引用。
- 支持继续追问、复制、重新生成、点赞和点踩。

### 使用洞察

- “高频问题”根据真实提问次数、继续追问和正向反馈生成。
- “高频引用文档”根据 `message_citations` 聚合，不使用虚构热门数据。
- 聚合结果必须遵守当前用户的租户和 Workspace 权限。

### 一键沉淀

用户可以把模型回答保存到已有 Workspace，作为独立 Markdown 文档重新进入知识循环。保存前允许编辑标题和正文，并记录来源：

```yaml
---
title: 商品主图优化策略
workspace_id: 01J...
source_type: ai_answer
model: gpt-5.5
question: 如何优化商品主图？
citations:
  - 商品搜索主图优化SOP.pdf
created_by: 01J...
created_at: 2026-08-01T00:00:00Z
---
```

保存后执行：创建业务 Asset -> 写入 Markdown 原文 -> GBrain `put_page` -> 更新索引与图谱。失败时不能显示“已沉淀”。

## 页面二：文档知识

### Workspace 与文档

- 创建个人或团队 Workspace，例如“电商运营知识库”“电商客服知识库”。
- 上传 Markdown、TXT、PDF、DOCX、XLSX，展示上传、解析、索引和失败状态。
- 支持搜索、筛选、排序、预览、下载、重试解析、归档和软删除。
- 右侧可在文档预览、当前范围问答、知识图谱之间切换。

### 文档图谱

- 选择 Workspace 时展示该 Workspace 内所有文档、主题、人物、项目、策略和 SOP 的真实关系。
- 选择文档节点后显示名称、类型、更新时间、100 字摘要、标签和关联文档。
- 点击节点进入对应文档预览。
- 图谱来自 GBrain `links`、`backlinks`、`traverse_graph`，不由前端伪造。

## 页面三：图片素材

### 类目与商品

- 创建图片类型 Workspace，例如“电商素材库”。
- Workspace 内建立一级、二级、三级叶子类目。
- 三级类目下创建具体商品，再向商品上传图片素材。
- 支持批量上传、缩略图、标签、搜索、筛选、移动和软删除。

### 图片理解与检索

- VLM 为每张图片生成约 100 字描述、OCR 文本、标签和视觉属性。
- 使用同一跨模态向量模型生成图片向量和文本查询向量。
- 图搜图：查询图片向量与素材图片向量相似度检索。
- 文搜图：文本向量与图片向量相似度检索。
- 图片原文件保存在 StorageProvider；图片向量保存在业务 PostgreSQL 的 pgvector；VLM 摘要和关系写入 GBrain。

### 图片图谱

- 展示 `类目 -> 商品 -> 图片 -> 主题/场景/风格` 的关系。
- 点击图片节点显示名称、缩略图、VLM 100 字摘要、所属类目和商品。
- 点击节点进入对应类目、商品或图片详情。

## 第一阶段不纳入范围

- Agent 执行中心、生图、生视频生成、会议机器人。
- 飞书、钉钉、Slack 自动同步。
- 多租户计费、套餐和公开分享链接。
- 视频知识库、视频在线编辑和复杂人工图谱编辑器。
- 前端 GBrain 运维后台。

第一阶段优先完成文档入库、带引用问答和回答自沉淀，再扩展完整图片检索。
